# Timeless Tiles Design System

Timeless Tiles uses a premium, calm architectural visual direction for homeowners, architects and interior designers, builders and contractors, and dealers. The core palette is warm neutral (`#FAF8F4`, `#211E1C`, `#FFFFFF`, `#F1EDE7`) with burgundy `#6F2435`, stone `#D9D0C6`, and restrained brass `#A87947` accents. Major headings use a local system-serif stack; body and interface text use a system sans-serif stack.

Tokens define modest radii, responsive container spacing, quiet shadows, keyboard-visible focus, accessible state colours, and reduced-motion behavior. Buttons use primary, secondary, outline, and ghost variants.

The project contains original local SVG brand, category, hero, and product artwork. Product renders are deterministic, material/finish-aware demo visualizations created from catalogue data. All product imagery is original demo artwork generated specifically for the academic project and does not represent photographs of real manufactured products. Responsive UI pages remain planned work.
