# Social Media Launch Readiness Guide

> **Official Disclaimer:**
> "Prepared for launch. External publishing is not executed because authorized social-account access was not provided."

This document details the step-by-step operational checklists, asset references, ad copy source links, CTA destination URLs, publishing schedules, UTM parameters, and pre/post-publication verification procedures for launching the Timeless Tiles digital marketing campaign across Instagram, Facebook, and YouTube.

---

## 1. Instagram Launch Checklist

- [ ] **Account Setup & Authorization:** Confirm access to official Instagram Business profile `@timelesstiles.official`.
- [ ] **Profile Optimization:** Link in bio set to `https://tiles-digital-platform.vercel.app?utm_source=instagram&utm_medium=social&utm_campaign=bio_link`.
- [ ] **Visual Verification:** Check asset dimensions (1080x1080 for feed, 1080x1920 for Stories/Reels covers).
- [ ] **Caption & Hashtags:** Copy captions and primary hashtag set (`#TimelessTiles #LuxuryTiles #HomeDecorIndia #TileDesign`).
- [ ] **CTA Link Verification:** Test bio link and Story swipe-up/sticker links.
- [ ] **Notification Setup:** Enable real-time notifications for comments and direct messages (DMs).

---

## 2. Facebook Launch Checklist

- [ ] **Page Authorization:** Confirm Admin/Editor role on official Facebook Business Page (`facebook.com/timelesstile25`).
- [ ] **Action Button:** Set primary Page Action Button to "Visit Website" pointing to `https://tiles-digital-platform.vercel.app?utm_source=facebook&utm_medium=social_page`.
- [ ] **Asset Verification:** Check landscape image dimensions (1200x630px).
- [ ] **Ad Account Connection:** Verify Meta Ads Manager account linking for boosting high-performing posts.
- [ ] **Lead Gen Form Setup:** Check instant lead form integration pointing to lead endpoint.
- [ ] **Messenger Auto-Responder:** Configure instant reply greeting pointing to WhatsApp / Website Enquiry.

---

## 3. YouTube Launch Checklist

- [ ] **Channel Authorization:** Confirm Manager access to official YouTube Channel (`youtube.com/@timelesstiles`).
- [ ] **Channel Art & Links:** Verify Channel Banner (`public/marketing/youtube/yt-channel-banner.svg`) and Channel Links pointing to site.
- [ ] **Video Upload / Premieres:** Upload video content MP4s (1920x1080 60fps).
- [ ] **Thumbnail Assignment:** Assign custom SVG thumbnails from `public/marketing/youtube/`.
- [ ] **Pinned Comments:** Add pinned comment with direct UTM product/guide link in every video.

## 9. UTM Parameter Naming Convention

All published external links must utilize strict standardized UTM query tags:

- **Format:** `https://tiles-digital-platform.vercel.app/[route]?utm_source=[channel]&utm_medium=[medium]&utm_campaign=[campaign_name]&utm_content=[post_id]`
- **Examples:**
  - Instagram Bio: `https://tiles-digital-platform.vercel.app/tiles?utm_source=instagram&utm_medium=social_bio&utm_campaign=brand_launch_2026`
  - Facebook Ad: `https://tiles-digital-platform.vercel.app/contact?utm_source=facebook&utm_medium=cpc&utm_campaign=architect_trade_leads&utm_content=fb_post_04`
  - YouTube Pinned Link: `https://tiles-digital-platform.vercel.app/guides/how-to-choose-tiles-for-each-room?utm_source=youtube&utm_medium=video_description&utm_campaign=educational_series`

## 10. Pre-Publication Checklist

Before clicking publish or launching paid campaigns:

- [ ] All graphics verified for clarity and accurate text rendering.
- [ ] Destination landing URLs tested on desktop and mobile devices.
- [ ] UTM parameters attached and tested.
- [ ] No unverified commercial claims (e.g., "#1 Tiles Brand in World" replaced with factual product specs).
- [ ] WhatsApp links verified and pre-filled message tested.
- [ ] Lead capture form tested to ensure submissions arrive in Supabase `enquiries` table.

---

## 11. Post-Publication Verification Checklist

Immediately following campaign publication:

- [ ] Confirm post displays correctly on public brand feed/page.
- [ ] Tap post link to verify HTTP 200 load on mobile device.
- [ ] Monitor post for first 60 minutes for customer questions or DMs.
- [ ] Record baseline initial impressions and engagement.
- [ ] Verify lead forms receive test submission cleanly.
