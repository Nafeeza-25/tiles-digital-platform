# Marketing Measurement Plan

**Plan only; no tracking is implemented.** This document defines metrics to consider after an appropriately reviewed deployment. No analytics, Meta Pixel, Google Ads conversion scripts, tracking cookies, consent manager, or measurement event code is added in this step. No actual values or results are claimed.

## Measurement questions

1. Are planned campaigns being seen by their intended audiences?
2. Which content earns meaningful engagement and sends visitors to useful pages?
3. Do visitors explore catalogue features and product details?
4. Which implemented enquiry paths do visitors use?
5. Do visitors interact with Store Finder contact actions?
6. Which organic search queries and pages are discoverable?

## KPI framework

| Area | Metrics | Interpretation |
|---|---|---|
| Awareness | Impressions, reach, video views | Exposure reported by each platform; definitions differ by platform. |
| Engagement | Social engagement rate, saves, shares, video completion, guide visits | Whether content is useful enough to interact with or continue exploring. |
| Website | Sessions, catalogue views, product detail views, search/filter use, recommendation starts, comparison usage | Whether visitors reach and use the implemented discovery features. Define event semantics before collection. |
| Lead generation | Contact submissions, quote submissions, product enquiries, WhatsApp clicks | Actions showing enquiry intent; clicks do not equal completed conversations or sales. |
| Store | Store Finder views, directions clicks, phone clicks | Interaction with fictional demo data in this project; real deployment requires verified locations. |
| SEO | Organic impressions, organic clicks, ranking queries, indexed pages | Search visibility and indexed coverage; use an appropriate search platform report. |

## Conceptual formulas

- **CTR** = clicks / impressions × 100
- **Conversion rate** = conversions / sessions × 100 (define the conversion and session scope first)
- **CPC** = ad spend / clicks
- **Cost per lead** = ad spend / leads
- **Engagement rate** = engagements / reach × 100 (state which engagement actions are included)
- **ROI concept** = (return − marketing cost) / marketing cost × 100 (define attributable return and cost; avoid interpretation where cost is zero)

These formulas are definitions, not calculated results. Actual performance cannot be calculated until valid campaign, spend, platform, and website data exist and attribution assumptions are documented.

## Reporting and data quality

- Report the date range, platform, metric definition, denominator, and data source with each KPI.
- Separate organic and paid activity and distinguish clicks from completed enquiries.
- Avoid combining platform metrics with different definitions without disclosure.
- Reconcile enquiry records with consent and privacy rules; minimize collected personal data and restrict access.
- Treat attribution as directional unless a valid, consent-aware measurement design supports stronger conclusions.
- Set numeric targets only after a baseline, project objective, and measurement capability are agreed; this academic plan invents none.

## Event definitions for a future implementation

If separately approved and privacy-reviewed, define events for catalogue/category view, product detail view, search/filter interaction, recommendation start, compare use, guide view, quote/contact/product-enquiry submission, WhatsApp click, Store Finder view, directions click, and phone click. Specify whether each event is a page view, intent action, or completed submission. Store Finder actions on fictional data must not be reported as real visits.

## No tracking in this step

This deliverable is a measurement framework only. Analytics tools, pixels, conversion tags, tracking cookies, and a consent manager are explicitly outside this step.
